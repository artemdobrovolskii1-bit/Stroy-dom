# Строй дом в РОССИИ — демо-сайты для строительной компании

Пять шаблонов сайта. Данные (адрес, телефон, отзывы) — образец. Откройте index.html — страница с тарифами.

- `1-start/` — Старт: сайт-визитка
- `2-vitrina/` — Витрина: лендинг с проектами и ценами
- `3-magazin/` — Магазин: каталог 50 проектов, фильтры, заявка на смету
- `4-premium/` — Премиум: конфигуратор дома, онлайн-бронь, зоны выезда, ипотека
- `5-premium-plus/` — Премиум+: 3D-модель дома (сборка при прокрутке), 3D-конфигуратор со сметой в PDF, планировка, график стройки, личный кабинет клиента, запись на встречу

В папке 5-premium-plus файл three.min.js (библиотека 3D-графики Three.js, лицензия MIT) должен лежать рядом с index.html.
